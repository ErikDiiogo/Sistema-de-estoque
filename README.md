# Sistema de Estoque Java

Sistema de gerenciamento de estoque desenvolvido em Java com menu interativo no console.

## Funcionalidades
- Adicionar produto (nome, preço e quantidade)
- Listar todos os produtos cadastrados
- Buscar produto por nome
- Remover produto por nome

## Como usar
1. Execute o arquivo `Main.java`
2. Escolha uma opção no menu
3. Siga as instruções na tela

## Tecnologias
- Java 21
- VS Code

## Conceitos aplicados
- Programação Orientada a Objetos (POO)
- Encapsulamento
- ArrayList e Coleções Java
- Scanner para entrada de dados
